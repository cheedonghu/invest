# 股票数据解析展示工程

这是一个最小可运行的股票估值展示项目：

- 后端使用 Python + FastAPI
- 数据源使用 AKShare
- 前端使用原生 HTML/CSS/JavaScript + ECharts
- 示例股票为招商银行（`600036`）
- 前端展示 PE/PB/PS 的历史均值与正负一个标准差，并对比季度市值、营收和净利润

## 启动方式

Windows 本地开发：双击项目根目录的 `start.bat`，或在终端运行 `./start.bat`。脚本会自动进入项目目录，使用 Conda 的 `invest` 环境启动服务，无需手动激活。打开 <http://127.0.0.1:8000/marked-stocks> 查看股票标记页，按 `Ctrl+C` 停止服务；启动失败时窗口会保留错误提示。

首次使用需已创建 `invest` 环境，并在该环境安装下述依赖。手动启动方式：

1. 安装依赖：

```bash
conda activate invest
pip install -r requirements.txt
```

2. 启动服务：

```bash
uvicorn backend.app.main:app --reload
```

3. 打开浏览器访问：

```text
http://127.0.0.1:8000
```

## 公司研究资料来源

所有 A 股公司的年报，优先从[巨潮资讯网](https://www.cninfo.com.cn/)检索和获取公告原文；半年报、季报及其他公告同样优先采用该来源。按公司名称或证券代码搜索，并核对报告年度和披露日期。

[宁德时代检索示例](https://www.cninfo.com.cn/new/fulltextSearch?notautosubmit=&keyWord=%E5%AE%81%E5%BE%B7%E6%97%B6%E4%BB%A3)。后续研究的来源规则见 [项目工作指引](AGENTS.md)。

## 数据口径与关注清单

- 市值与业绩图按财报期末匹配此前最近交易日市值；提示中显示实际交易日。页面的最新市值另取最近有效交易日。
- 营收与合并净利润采用 TTM：当期累计 + 上年全年 - 上年同期累计；全年直接取年报。缺少历史数据时不做年化推算。该图用于历史比较，财报期末不代表披露日期。
- 资产负债表兼容新浪与东方财富字段，合计科目优先于其明细，避免重复计入；报表总额与已分类金额的差额明确展示，不丢弃负值。
- 图表将一年内到期的非流动负债并入“其他流动负债”，在悬浮明细保留原科目；新浪“长期递延收益”按财报“递延收益”列明，其他非流动负债保留具体科目。
- 字段先统一全半角、空白和大小写，再按明确的别名表映射为统一科目。空值可由同义字段补齐，零值保留；同义字段金额冲突时切换数据源并记录错误。原始字段名保存在标准化数据的 `balance_field_sources` 中，未识别金额通过报表合计差额明确展示。
- 同义名称与“合计—明细”关系分别处理，例如公允价值计入损益的金融资产/负债合计优先于交易性及指定为公允价值计量的组成部分，缺少合计时才加总明细。
- 已标记股票支持搜索代码、名称和备注，按更新时间、添加时间、代码或名称排序；可直接打开对应股票的走势与资产负债表。列表保存和刷新保留其他未保存修改。
- 首页和股票标记页统一使用“备注”，支持 Markdown 原文编辑、预览及保存后的排版展示，包括标题、加粗、列表、链接、引用、代码块和表格。每份备注最多 100000 个字符，保留原文的缩进与行尾空格；渲染组件随项目提供，并清洗输出内容。
- 股票标记页采用“纸感研究笔记”布局：左侧公司目录，右侧完整阅读备注；新增备注使用独立窗口，切换公司、搜索、排序和刷新保留未保存的修改。首页备注入口可展开录入。
- 备注页的“删除”会清除备注并将股票移出标记列表，保留股票名称、行情和财报数据；删除前提示确认，失败时保留备注和草稿。
- 已有数据库发布此版本前需执行 [备注长文本迁移](db/migrations/2026-10-25-stock-notes.sql)，将 `stock_info.mark_reason` 扩展为 `MEDIUMTEXT`。字段名和现有接口参数保持兼容；新建数据库的建表语句已同步更新。
